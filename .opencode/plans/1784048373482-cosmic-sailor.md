# Rename plugin to "Cyclist" implementation plan

## Goal

Rename the plugin user-facing identity and internal identifiers from the old "Toggle Read-Source-Preview" / `toggleReadSourcePreview` naming to **"Cyclist"** / `cyclist`.

Scope: plugin name + command label + IDs (as user selected). This means the Obsidian plugin ID also changes.

> **Warning:** Changing the plugin `id` in `manifest.json` means Obsidian will treat the renamed plugin as a different plugin; users who installed the old ID will have to reinstall and reassign hotkeys.
